# Design system — Home Budget Finance

L'identité visuelle reste personnelle à Home Budget : surfaces claires, formes généreuses, forte hiérarchie typographique, accent configurable et contraste net entre revenus, dépenses et transferts.

## Signature

- marque : `HB` ;
- produit : `Home Budget Finance` ;
- promesse : un cockpit personnel pour comprendre où va l'argent ;
- accent par défaut : Océan `#3569ff` ;
- alternatives : Violet et Émeraude ;
- arrondis principaux : 24 à 30 px ;
- panneaux : blanc / slate 900 en mode sombre.

## Couleurs métier

- revenu : emerald ;
- dépense : rose ;
- transfert : sky ;
- budget / action principale : accent utilisateur.

## Principes UX

1. les montants importants apparaissent avant les graphiques ;
2. les transferts sont visuellement distincts des dépenses ;
3. les actions créatrices sont toujours clairement visibles ;
4. un état vide explique quoi faire ensuite ;
5. le thème et l'accent sont mémorisés localement ;
6. l'interface ne dépend d'aucune donnée de démonstration.
